# CAD-модели экспериментальной установки

Параметрические 3D-модели модульной светоизолированной установки для 
видеорегистрации поведения Daphnia spp. Модели разработаны в среде 
OpenSCAD и изготовлены методом FDM-печати из PLA-пластика.

## Структура файлов

| Файл | Деталь | Назначение |
|------|--------|------------|
| `01_base.scad` | Основание (кубический корпус) | Размещение чашки Петри |
| `02_cone.scad` | Усечённый конус | Световой адаптер с LED-лентой |
| `03_diaphragm.scad` | Диафрагма | Светорассеиватель (белый PLA) |
| `04_spacer.scad` | Дистанционное кольцо | Проставка для высоты (3 шт.) |
| `05_lid_with_cam_mount.scad` | Крышка с креплением | Установка веб-камеры Logitech C270 |
| `assembly.scad` | Общая сборка | Все детали вместе |

## Использование

1. Установите [OpenSCAD](https://openscad.org/)
2. Откройте нужный `.scad` файл
3. При необходимости измените параметры в начале файла 
   (например, `box_width`, `wall_thickness`)
4. Экспортируйте в STL: **File → Export → STL**
5. Загрузите STL в слайсер для 3D-печати

## Общие параметры

- Материал печати: PLA чёрного цвета (кроме диафрагмы — белая)
- Толщина стенки: 5 мм
- Общая высота установки в сборе: ~230 мм
- Рабочая ёмкость: чашка Петри диаметром 80 мм

## Лицензия

Модели созданы в рамках ВКР и доступны для использования в 
исследовательских и образовательных целях.
