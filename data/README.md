# Датасеты для обучения моделей Случайного Леса и модели YOLO26n

В данной директории размещены датасеты, сформированные на основе координат траекторий движения Daphnia spp.

## Структура датасетов для обучения Случайного Леса

Каждый CSV-файл содержит следующие колонки:
- `track_id` — идентификатор трека особи
- `window_start_frame` — начальный кадр временного окна
- `avg_speed` — средняя скорость
- `total_distance` — общее пройденное расстояние
- `straightness` — прямолинейность траектории
- `median_speed` — медианная скорость
- `mean_turning_angle` — средний угол поворота
- `angular_velocity` — угловая скорость
- `jump_frequency` — частота прыжков
- `label` — метка класса (0 — чистая вода, 1 — токсичная среда)

## Формирование данных

Датасеты сформированы из координат траекторий, полученных после трекинга видео с помощью модели YOLO26n и алгоритма TrajectoryMerger.

### Источники данных:
- Чистая вода (label = 0): 30-минутные записи в лайтбоксе
- Токсичная среда (label = 1): записи с воздействием ионов меди (50 мкг/л)
