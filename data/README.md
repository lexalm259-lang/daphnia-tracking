# Датасеты для обучения моделей Случайного Леса и модели YOLO26n

В данной директории размещены датасеты, сформированные на основе координат траекторий движения Daphnia spp.

# Структура датасетов для обучения Random Forest

## Описание колонок

Каждый CSV-файл содержит следующие базовые колонки:

### Основные признаки:
- `track_id` — уникальный идентификатор трека особи
- `label` — метка класса (0 — чистая вода, 1 — токсичная среда с ионами меди)
- `window_start_frame` — начальный кадр временного окна анализа
- `avg_speed` — средняя скорость перемещения (пикселей/кадр)
- `total_distance` — общее пройденное расстояние (пикселей)
- `straightness` — индекс прямолинейности траектории (0–1)
- `median_speed` — медианная скорость (пикселей/кадр)
- `mean_turning_angle` — средний угол поворота (градусы)
- `angular_velocity` — угловая скорость (градусы/кадр)
- `jump_frequency` — частота скачкообразных ускорений (событий/сек)

### Дополнительные признаки (для датасетов с агрегацией):
- `speed_X_mean/max/std` — статистики скорости по подокнам
- `angle_X_mean/std` — статистики углов поворота по подокнам
- `jump_X_max` — максимальная частота прыжков в подокнах

### Сложные признаки (для 5-минутных окон):
- `trajectory_entropy` — энтропия распределения координат
- `fractal_dimension` — фрактальная размерность траектории
- `sinuosity` — коэффициент извилистости пути
- `velocity_autocorrelation` — автокорреляция скорости (лаг=1)

## Формирование данных

Датасеты сформированы из координат траекторий *Daphnia spp.*, полученных после многоцелевого трекинга видеозаписей с помощью:

- **Модели детекции:** YOLO26n (Ultralytics)
- **Алгоритма трекинга:** TrajectoryMerger (венгерский алгоритм с восстановлением идентичности)

### Источники данных:
- Чистая вода (label = 0): записи с чистой водой
- Токсичная среда (label = 1): записи с воздействием ионов меди (50 мкг/л)

Датасеты используются для обучения моделей Random Forest
